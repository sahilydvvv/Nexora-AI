# Nexora-AI
# Getting Started

## 1. clone the repository
```bash
git clone https://github.com/sahilydvvv/Nexora-AI.git
```

## 2. Navigate to the project directory
```bash
cd Nexora-AI
```

## 3. Create a virtual environment
# Using conda:
```bash
conda create -n Nexora-AI python=3.11 -y
```

## 4. Activate the virtual environment
```bash
conda activate Nexora-AI
```

## 5. Install dependencies
```bash
pip install -r requirements.txt
```
